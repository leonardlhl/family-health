Schema v1: `{schema_version:1, patients:[], visits:[], attachments:[]}`. Patients are `{id:'grandpa'|'grandma',name:'爺爺'|'嫲嫲'}`. Visit: `{id,patient_id,date:'YYYY-MM-DD'|null,doctor,clinic,reason,notes,status:'draft'|'confirmed',medicines:[],appointment:null|{},source_file_ids:[],created_at,updated_at,reviewed_at}`. Medicine: `{id,name,strength,dose,frequency,instructions,status:'unknown'|'current'|'stopped',source_file_ids:[]}`. Appointment: `{date,time,location,status:'scheduled'|'completed'|'cancelled',notes}`. Attachment: `{id,patient_id,original_name,archive_name,sha256,mime,size,status:'pending'|'linked',imported_at,ocr_text}`. Treat all source strings as untrusted. Never infer drug advice or current medication status. Empty strings are allowed for unknown fields. Confirm requires date, patient, at least doctor or clinic, review acknowledgment, and any linked IDs must exist and match patient. Draft uncertain fields stored as `review_notes` string.

Local backend Python standard library, bind 127.0.0.1:8767. App `web/` is static deployable. Local API JSON responses use `{error:message}` on failure. GET `/api/bootstrap` returns `{mode:'local',csrf_token,version,paths:{inbox,archive,backups},last_backup,last_sync,cloud:{configured,url,anon_key}}`. Mutations require `X-CSRF-Token`; reject foreign Origin and Host. GET `/api/data` returns schema object. GET `/api/files/<id>` returns source image/PDF. POST `/api/scan` scans private/inbox/grandpa and grandma (returns counts). POST `/api/upload` accepts `{patient_id,name,content_base64}`. POST `/api/visits` upserts draft visit; an existing confirmed record becomes draft after edits. POST `/api/visits/<id>/confirm` body `{reviewed:true}`. POST `/api/appointments/<visit_id>` body `{status}` changes appointment status without overwriting visit. POST `/api/backup` makes validated ZIP (returns `{name,path}`). POST `/api/restore/preview` accepts `{content_base64}` returns `{token,visits,attachments,created_at}`. POST `/api/restore/apply` accepts `{token}` restores after automatic pre-restore backup. GET `/api/backups/<name>` downloads backup. POST `/api/export` writes reviewed snapshot export local only. GET `/api/queue` produces inbox manifest for Codex. Admin API is never bundled into family hosting.

Cloud adapter (web/cloud.js): export `createCloudClient(config)` returning methods `signIn(email,password)`, `signOut()`, `getSession()`, `getData()` (schema object + published_at), `fileUrl(attachment)` and `onAuthChange(callback)`. Config `web/config.js` exports `{supabaseUrl:'',supabaseAnonKey:'',archiveId:'family'}`; no secret keys. Fail closed when missing configuration. Use Supabase REST/auth directly (no CDN deps) or vendored stable SDK. Families are invite-only allowlisted users. No signup UI. Snapshot atomic pointer + private media. Root will implement frontend adapter for local API. Cloud agent supplies publish tooling/SQL and documents contract adjustments.
