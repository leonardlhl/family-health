Schema v1: `{schema_version:1, patients:[], visits:[], attachments:[]}`. Patients are `{id:'grandpa'|'grandma',name:'爺爺'|'嬷嬷'}`. Visit: `{id,patient_id,date:'YYYY-MM-DD'|null,doctor,clinic,reason,notes,status:'draft'|'confirmed',medicines:[],appointment:null|{},source_file_ids:[],created_at,updated_at,reviewed_at}`. Medicine: `{id,name,strength,dose,frequency,instructions,status:'unknown'|'current'|'stopped',source_file_ids:[]}`. Appointment: `{date,time,location,status:'scheduled'|'completed'|'cancelled',notes}`. Attachment: `{id,patient_id,original_name,archive_name,sha256,mime,size,status:'pending'|'linked',imported_at,ocr_text}`. Treat all source strings as untrusted. Never infer drug advice or current medication status. Empty strings are allowed for unknown fields. Confirm requires date, patient, at least doctor or clinic, review acknowledgment, and any linked IDs must exist and match patient. Draft uncertain fields stored as `review_notes` string.

Local backend Python standard library, bind 127.0.0.1:8767. App `web/` is static deployable. Local API JSON responses use `{error:message}` on failure. GET `/api/bootstrap` returns `{mode:'local',csrf_token,version,paths:{inbox,archive,backups},last_backup,last_sync,cloud:{configured,url,anon_key}}`. Mutations require `X-CSRF-Token`; reject foreign Origin and Host. GET `/api/data` returns schema object. GET `/api/files/<id>` returns source image/PDF. POST `/api/scan` scans private/inbox/grandpa and grandma (returns counts). POST `/api/upload` accepts `{patient_id,name,content_base64}`. POST `/api/visits` upserts draft visit; an existing confirmed record becomes draft after edits. POST `/api/visits/<id>/confirm` body `{reviewed:true}`. POST `/api/appointments/<visit_id>` body `{status}` changes appointment status without overwriting visit. POST `/api/backup` makes validated ZIP (returns `{name,path}`). POST `/api/restore/preview` accepts `{content_base64}` returns `{token,visits,attachments,created_at}`. POST `/api/restore/apply` accepts `{token}` restores after automatic pre-restore backup. GET `/api/backups/<name>` downloads backup. POST `/api/export` writes reviewed snapshot export local only. GET `/api/queue` produces inbox manifest for Codex. Admin API is never bundled into family hosting.

Cloud adapter (web/cloud.js): export `createCloudClient(config)` returning methods `signIn(email,password)`, `signOut()`, `getSession()`, `getData()` (schema object + published_at), `fileUrl(attachment)` and `onAuthChange(callback)`. Reports extension (schema_version remains 1): optional missing `reports` means []; a present non-array is rejected. Report fields: `{id,patient_id,date,title,category,facility,doctor,summary,notes,review_notes,status,privacy_reviewed,source_file_ids,created_at,updated_at,reviewed_at}`. No identity fields. POST /api/reports upserts a draft; /api/reports/<id>/confirm requires reviewed:true, valid date/title, resolved notes, >=1 same-person privacy-checked source. Report changes invalidate confirmation. Family projection and cloud publication include only confirmed reports; file manifest is the exact same-person source union of confirmed visits and reports. Reports do not become medication rows.

POST /api/upload may include kind:'report' (default 'visit'). Explicit import-folder entries may have kind:'report'; only those are recursively scanned within bounded depth/count and resolved root, excluding links. Report confirmation creates stable-ID-backed date_title archive subfolders and ordered alias filenames. Paths never include patient names. GET /api/files/<id>/pdf-info returns pages/page_sizes/render_dpi/max_edge/sha256/privacy_checked; GET /api/files/<id>/page/<zero-based index> returns a preview PNG. POST /api/files/<id>/sanitize-pdf requires source_sha256, pages:[{page,boxes:[{x,y,w,h}]}] in normalized rendered coordinates, all exact unique indexes in reviewed_pages, privacy_checked:true. Only raster-rebuilt metadata-free PDFs can pass. Source changes invalidate stale reviews. PDF cap50,000,000 bytes/80pages plus bounded pixel resources. Pending PDF page renders excluded from backup.

Current manifest alone authorizes reads. An unchanged full snapshot skips publication only after remote snapshot/asset verification. No automatic deletion or share-token rotation.
